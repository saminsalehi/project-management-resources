# Project Management Resources by Samin Salehi, PMP

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24490626.svg)](https://doi.org/10.5281/zenodo.24490626) [![ORCID](https://img.shields.io/badge/ORCID-0009--0005--4143--2816-A6CE39?logo=orcid&logoColor=white)](https://orcid.org/0009-0005-4143-2816) [![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](LICENSE)

Free, practical project management guides, checklists and templates for new project managers, project coordinators and PMP® candidates.

The material is adapted from the **[Project Manager Land](https://www.youtube.com/@ProjectManagerLand)** YouTube channel, created by **Samin Salehi**, a PMP-certified Project Manager in the Greater Toronto Area, Canada, with 8 years of project management experience in commercial construction, architectural millwork, interior fit-outs and healthcare projects.

> Make project management easy to understand, practical and useful in the real world.

## About the author

**Samin Salehi, PMP** is a Project Manager in the Greater Toronto Area, Ontario, Canada, with 8 years of project management experience. Samin's work spans commercial construction, architectural millwork and interior fit-out projects, and includes healthcare-related projects. Samin holds the Project Management Professional (PMP®) certification and created Project Manager Land, a YouTube channel that teaches practical project management to beginners, project coordinators and PMP candidates.

## How this was made

The ideas, examples and teaching approach come from Samin Salehi's published Project Manager Land videos, which are linked from each guide. The written adaptations, checklists and templates were drafted with help from an AI assistant (Claude, by Anthropic) and reviewed for accuracy against the original videos. Each guide says which parts restate the source video and which are general project management practice.
