# Glossary of Project Management Terms

*Samin Salehi, PMP · Project Manager Land · Plain-language definitions used in this repository*

| Term | Plain-language definition |
|------|---------------------------|
| **Acceptance criteria** | The conditions a deliverable must meet before the approver accepts it |
| **Actual cost (AC)** | What the completed work has actually cost so far |
| **Agile** | An adaptive approach that delivers in short cycles and expects requirements to evolve (e.g. Scrum, Kanban) |
| **Baseline** | The approved version of the scope, schedule or budget that progress is measured against |
| **Change control** | The process for assessing and approving or rejecting changes before they're added |
| **Critical path** | The longest chain of dependent tasks. Delaying any of them delays the finish date. |
| **Dependency** | A task that can't start or finish until another task does |
| **Deliverable** | A tangible result the project must produce |
| **Earned value (EV)** | The budgeted cost of the work actually completed |
| **Gantt chart** | A bar chart showing tasks on a timeline |
| **Issue** | A problem that has already happened and is affecting the project |
| **Lessons learned** | What the team would repeat or change, recorded for future projects |
| **Milestone** | A significant point or event in the schedule, with no duration |
| **Operations** | Ongoing, repeatable work, as opposed to a temporary project |
| **Planned value (PV)** | The budgeted cost of the work scheduled to be done by now |
| **Project** | A temporary effort to reach a clear result, with a start and a finish |
| **Project charter** | The document that authorizes a project and states its goal, sponsor and high-level scope |
| **RACI** | A responsibility matrix: Responsible, Accountable, Consulted, Informed |
| **Risk** | Something that might happen and would affect the project |
| **Risk register** | The list of risks with their likelihood, impact, owner and response |
| **Scope** | What the project will (and won't) deliver |
| **Scope creep** | Uncontrolled growth in scope without matching changes to time or budget |
| **Stakeholder** | Anyone who affects, or is affected by, the project |
| **Three-point estimate** | An estimate built from optimistic, most likely and pessimistic durations |
| **Triple constraint** | Scope, time and cost are linked. Changing one affects the others. |
| **Waterfall** | A predictive approach that plans the work up front and runs it in sequence |
| **WBS (work breakdown structure)** | Deliverables broken down into smaller, manageable pieces of work |
